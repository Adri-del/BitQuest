# BITQUEST - EXPLORADOR DE MATRICES
***

## Descripcion

BitQuest es un videojuego de consola desarrollado en lenguaje C y NASM. El jugador deberá explorar laberintos representados mediante matrices, recolectar monedas, encontrar una llave, abrir una puerta y alcanzar la salida para completar cada uno de los cuatro niveles disponibles.

***

## Requirimientos

Se debe de contar con:

* NASM
* GCC
* Windows SO

***

## Contenido del ZIP

* build.bat
* juego.c
* juego.h
* main.c
* mapas.h
* rutinas.asm
* nivel1.txt
* nivel2.txt
* nivel3.txt
* nivel4.txt

***

## Compilacion

Abra una terminal dentro de la carpeta principal del proyecto y ejecute:

build.bat
